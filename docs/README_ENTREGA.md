## Pendientes humanos obligatorios

1. Cada integrante debe jugar tres corridas en solitario y llenar su bitácora.
2. Grabar el gameplay real y la cinemática generada por IA.
3. Subir el video a YouTube, Vimeo o Drive con acceso público.
4. Crear un repositorio público en GitHub y subir este proyecto.
5. En Settings > Pages, seleccionar GitHub Actions como fuente.
6. Confirmar que la acción terminó y copiar el enlace público.

## Controles

- P1: WASD, F para disparar, G para impulso.
- P2: flechas, K para disparar, L para impulso.
- Mandos: stick izquierdo para mover, derecho para apuntar, gatillo o A para
  disparar y B para impulso.
- P pausa la partida.
- R reinicia después de victoria o derrota.
